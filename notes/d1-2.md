## Why this matters

Today's programs practise data types and type conversion, today's main topic. Placement MCQs often show a short program and ask for its output, so writing and predicting small programs builds that skill directly.

## Core concepts

### Checking and converting types

- type(x) tells you the type of x.
- int(), float(), str() and bool() convert values.
- isinstance(x, int) checks whether x is an int and returns True or False.

### Reading several values on one line

```python
a, b = input("Enter two numbers: ").split()
a, b = int(a), int(b)
# shorter form
a, b = map(int, input().split())
```

## Worked examples

### Program 1: Type detective

**Problem:** Read any value and print its type after trying to convert it to int, then float, else keep it as text.

Sample input: `6.5`
Sample output: `6.5 is a float`

Hint: use try and except. You will learn them properly in week 4, so copy the pattern for now.

### Program 2: Rupees and paise

**Problem:** Read an amount like 249.75 and print rupees and paise separately.

Sample input: `249.75`
Sample output: `249 rupees and 75 paise`

Hint: use int() for rupees and round() on the remainder × 100 for paise.

### Program 3: Marks percentage

**Problem:** Read obtained marks and total marks as integers and print the percentage to 2 decimals.

Sample input: `437 500`
Sample output: `Percentage: 87.40%`

### Program 4: Truthy checker

**Problem:** Read a line of text and print whether it is empty, using bool().

Sample input: an empty line
Sample output: `You typed nothing`

### Program 5: Seconds converter

**Problem:** Read seconds as an integer and print hours, minutes and seconds in the format HH:MM:SS.

Sample input: `3725`
Sample output: `01:02:05`

Hint: use //, % and an f-string with :02d.

## Common mistakes

- Using split() and forgetting to convert each part to int.
- Rounding paise wrongly because of float error. Round after multiplying by 100.
- Printing percentages without the % sign or without 2 decimals.

## Interview and test questions

**What does `print(int("7") + float("2.5"))` print?**
9.5.

**What does `map(int, "1 2 3".split())` give?**
An iterator of the ints 1, 2 and 3. Wrap it in list() to see them.

**What is the output of `f"{5:02d}"`?**
05.

## Quick recap

- type() and isinstance() check types, and int(), float(), str() and bool() convert them.
- Use split() with map() to read several numbers from one line.
- Round money after converting to the smallest unit.
- Format numbers with f-strings, such as :.2f and :02d.

## Solutions

### Program 1

```python
value = input("Enter a value: ")
try:
    int(value)
    kind = "an int"
except ValueError:
    try:
        float(value)
        kind = "a float"
    except ValueError:
        kind = "a string"
print(f"{value} is {kind}")
```

### Program 2

```python
amount = float(input("Amount: "))
rupees = int(amount)
paise = round((amount - rupees) * 100)
print(f"{rupees} rupees and {paise} paise")
```

### Program 3

```python
obtained, total = map(int, input("Obtained and total: ").split())
print(f"Percentage: {obtained / total * 100:.2f}%")
```

### Program 4

```python
text = input("Type something: ")
if bool(text):
    print("You typed:", text)
else:
    print("You typed nothing")
```

### Program 5

```python
s = int(input("Seconds: "))
h = s // 3600
m = (s % 3600) // 60
sec = s % 60
print(f"{h:02d}:{m:02d}:{sec:02d}")
```
