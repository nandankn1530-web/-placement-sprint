## Core concepts

### The input, process, output pattern

Almost every beginner program follows three steps:

1. **Input**: read values with input() and convert them.
2. **Process**: calculate with operators.
3. **Output**: print the result clearly with an f-string.

### Useful operators for today

| Operator | Meaning | Example | Result |
| --- | --- | --- | --- |
| + | Add | 7 + 2 | 9 |
| - | Subtract | 7 - 2 | 5 |
| * | Multiply | 7 * 2 | 14 |
| / | Divide, gives a float | 7 / 2 | 3.5 |
| // | Floor division | 7 // 2 | 3 |
| % | Remainder | 7 % 2 | 1 |
| ** | Power | 7 ** 2 | 49 |

## Worked examples

### Program 1: Student card

**Problem:** Read a name, roll number and CGPA, then print them as one line.

Sample input: Nandan, 21EI045, 6.5
Sample output: `Nandan (21EI045) - CGPA 6.5`

Hint: CGPA needs float().

### Program 2: Simple interest

**Problem:** Read principal, rate and time, then print simple interest and total amount in rupees.

Sample input: 10000, 8, 2
Sample output: `Interest: Rs 1600.00, Amount: Rs 11600.00`

Hint: SI = P × R × T / 100.

### Program 3: Minutes to hours

**Problem:** Read a number of minutes and print it as hours and minutes.

Sample input: 135
Sample output: `2 hours 15 minutes`

Hint: use // and %.

### Program 4: Average of three marks

**Problem:** Read marks in three subjects and print the total and the average rounded to 2 decimals.

Sample input: 78, 85, 69
Sample output: `Total: 232, Average: 77.33`

### Program 5: Train ticket split

**Problem:** A ticket costs a total amount for a group. Read the total and the number of friends, then print each person's share and the leftover rupees if the amount does not divide evenly.

Sample input: 1000, 3
Sample output: `Each pays Rs 333, Rs 1 left over`

Hint: use // for the share and % for the leftover.

## Common mistakes

- Forgetting int() or float() around input().
- Using / when you need a whole number. Use // instead.
- Printing without labels, which makes output hard to read in tests.

## Interview and test questions

**What is the output of 17 // 5 and 17 % 5?**
3 and 2.

**What type does 10 / 2 return?**
A float: 5.0.

**What does round(77.3333, 2) return?**
77.33.

## Solutions

### Program 1

```python
name = input("Name: ")
roll = input("Roll number: ")
cgpa = float(input("CGPA: "))
print(f"{name} ({roll}) - CGPA {cgpa}")
```

### Program 2

```python
p = float(input("Principal: "))
r = float(input("Rate: "))
t = float(input("Time in years: "))
si = p * r * t / 100
print(f"Interest: Rs {si:.2f}, Amount: Rs {p + si:.2f}")
```

### Program 3

```python
minutes = int(input("Minutes: "))
print(f"{minutes // 60} hours {minutes % 60} minutes")
```

### Program 4

```python
a = int(input("Mark 1: "))
b = int(input("Mark 2: "))
c = int(input("Mark 3: "))
total = a + b + c
print(f"Total: {total}, Average: {total / 3:.2f}")
```

### Program 5

```python
total = int(input("Total amount: "))
friends = int(input("Number of friends: "))
print(f"Each pays Rs {total // friends}, Rs {total % friends} left over")
```
