## Why this matters

Python is the one language you will use for coding rounds and for AI/ML. Today you set up your computer and write your first programs. Every later topic, from DSA to machine learning, runs on this setup.

## Core concepts

### Installing Python

1. Go to python.org, open Downloads, and download the latest Python 3 for Windows.
2. Run the installer. **Tick "Add python.exe to PATH"** on the first screen. This step is the one people forget most.
3. Click Install Now.
4. Open Command Prompt and type the command below. You should see a version number such as Python 3.13.

```
python --version
```

### Installing VS Code

1. Download VS Code from code.visualstudio.com and install it.
2. Open VS Code, go to Extensions, and install the **Python** extension by Microsoft.
3. Create a folder called `python-practice` and open it in VS Code with File, Open Folder.
4. Create a file named `hello.py`, write code, and press the Run button at the top right.

### print()

`print()` shows output on the screen.

```python
print("Hello, Nandan")
print("Marks:", 85)           # items are separated by a space
print("A", "B", "C", sep="-")  # A-B-C
print("Same line", end=" ")
print("continues here")
```

### Variables

A variable is a name that stores a value. Python works out the type by itself.

```python
name = "Nandan"      # str
age = 22             # int
cgpa = 6.5           # float
is_final_year = True # bool
print(name, age, cgpa, is_final_year)
```

Naming rules:

- Names can use letters, digits and underscores, but cannot start with a digit.
- Names are case-sensitive, so `Marks` and `marks` are different.
- You cannot use keywords such as `if`, `for` or `class` as names.
- Use clear names in snake_case, such as `total_marks`.

### input()

`input()` reads text typed by the user. **It always returns a string.** Convert it when you need a number.

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))
print("Hello", name, "you will be", age + 1, "next year")
```

### f-strings

An f-string puts values inside text neatly.

```python
name = "Nandan"
cgpa = 6.5
print(f"{name} has a CGPA of {cgpa}")
print(f"Rounded: {3.14159:.2f}")   # 3.14
```

### Comments

A line that starts with `#` is a comment. Python ignores it. Use comments to explain why the code does something.

## Worked examples

### Example 1: Simple profile

```python
name = input("Name: ")
branch = input("Branch: ")
year = int(input("Year of passing: "))
print(f"{name} | {branch} | Passing out in {year}")
```

### Example 2: Swap two variables

```python
a = 10
b = 20
a, b = b, a
print(a, b)   # 20 10
```

### Example 3: Area of a rectangle

```python
length = float(input("Length in metres: "))
width = float(input("Width in metres: "))
area = length * width
print(f"Area = {area:.2f} square metres")
```

## Common mistakes

- Forgetting to tick "Add to PATH", so `python` is not recognised in Command Prompt.
- Adding a number to input directly, such as `input() + 1`. This fails because input is text.
- Mixing quotes, such as `"Hello'`.
- Naming your file `random.py` or `math.py`, which hides Python's built-in modules.
- Wrong indentation. Python uses spaces to group code, so keep lines at the start unless inside a block.

## Interview and test questions

**Is Python compiled or interpreted?**
Python is usually called interpreted. Code is first compiled to bytecode and then run by the Python virtual machine.

**What does input() return?**
Always a string, so you convert it with int() or float() when you need a number.

**What is dynamic typing?**
A variable's type is decided when the program runs, and the same name can later hold a different type.

**What is the output of print(10, 20, sep="-")?**
10-20.

**Can a variable name start with a digit?**
No. It must start with a letter or an underscore.
